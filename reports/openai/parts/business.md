# OpenAI：商业模式、产品与用户研究

数据截止：2026-10-04（Asia/Shanghai）；研究时通过 `date` 验证。公开资料研究，不是投资建议。分析师：business-decoder。

## 核心判断

OpenAI把计算资源和模型研发转化为普通人、企业与开发者可以直接使用的知识工作能力，按订阅、用量和商业意图变现。*这是“前沿研究 + 算力供应 + 软件分发”的混合生意；用纯SaaS的高毛利、低边际成本假设估值，容易高估利润。需求已得到规模验证，股东回报仍取决于交付成本、用户留存与融资稀释。*

商业模式与用户维度评分 **4.0 / 5**（主观研究判断，置信度中等）；信息完整度：**适中**。产品与采用证据较多，单位经济与留存证据不足。

置信度：🟢高表示可核实的官方披露或正式产品条款，**不代表经过审计**；🟡中表示可信媒体或有约束的推理；🔴低表示未经验证的推算。斜体为研究判断。

## 1. 生意本质与需求刚性

一句话：让人和企业用更少时间完成以前需要检索、写作、分析、编程或协调的工作。

*客户购买的最终产品并不是Token，而是“可靠完成工作的能力”。学生购买学习辅助，专业人士购买时间，大企业购买可治理的生产能力，开发者购买可以嵌入自己产品的智能。模型回答正确、行动成功、可追溯和权限安全，比单独的参数规模更重要。*

如果OpenAI不存在，客户仍可采用人工工作、搜索、传统办公软件、Claude/Gemini、开源模型及内部部署。*因此需求是真实需求，OpenAI并非唯一供给者。通用问答和轻量写作的替代成本低；已经连接数据、建立评测和权限治理的生产工作流迁移成本较高。经济下行时，能证明节省人工成本的企业部署具有韧性，娱乐式个人订阅和未证明ROI的试点容易被削减。*

官方消费者研究（2025-09-15，样本150万次对话）发现大约七成使用与非工作有关，约四分之三对话集中于实用指导、信息查询和写作；这说明需求覆盖日常生活，不能把全部消费者使用换算成企业生产力收益。[OpenAI：How people are using ChatGPT](https://openai.com/index/how-people-are-using-chatgpt/) 🟢官方研究、受样本和分类方法限制。

## 2. 收入机制与质量

| 收入线 | 付费触发与经济机制 | 收入质量判断 | 证据与缺口 |
|---|---|---|---|

| 企业/团队订阅 | 按人员、服务等级、合同及用量扩张 | *治理、采购和工作流形成更高粘性，但部署ROI需要验证* | 2026-04-08企业贡献超过40%收入，年底与消费者持平是目标不是已实现结果。[企业战略](https://openai.com/index/next-phase-of-enterprise-ai/) 🟢官方管理层披露 |
| API及智能体用量 | 输入/输出/缓存Token、工具调用和不同服务等级 | *与生产负载关联，有重复消费；不保证未来承诺* | GPT-6.1 Sol标准价输入$2、输出$10、缓存输入$0.10/百万Token；2026-09-29。[模型发布](https://openai.com/index/introducing-gpt-6-1-sol/) 🟢 |
| 广告 | Free/Go用户的商业意图由广告主购买 | *扩大免费层变现，存在信任和体验约束* | 2026-02-09起美国测试；Plus/Pro/Business/Enterprise/Edu无广告。广告独立于回答是公司政策承诺，不是收入质量审计。[广告FAQ](https://help.openai.com/en/articles/20001047-ads-in-chatgpt) 🟢 |
| 电商交易 | 商家对已完成Instant Checkout交易支付费用 | *更接近交易佣金；不能把GMV当收入* | 2025-09-29推出，商家是merchant of record，支付和履约仍由商家承担；具体Take Rate及GMV数据缺失。[购物发布](https://openai.com/index/buy-it-in-chatgpt/) 🟢 |
| 授权、成果/IP分成 | 管理层提出未来方向 | *不能提前计入成熟收入线* | CFO 2026-01-18描述授权/IP/成果定价为未来模式。[商业模式说明](https://openai.com/index/a-business-that-scales-with-the-value-of-intelligence/) 🟢为“公司表态”，不是收入已实现 |

*收入结构正在从个人订阅向组织和工作负载延伸，但官方“enterprise”定义是否包含全部API、各产品交叉计费如何分类，没有公开可审计分部表。企业收入占比不能直接解释为高毛利率或净留存率。*

客户集中度、前五大客户收入、渠道分成、合同平均期限、净收入留存NRR、退款及收入确认细则：**数据缺失**。未发现可据以判断提前确认收入的审计材料，不能据此断言存在或不存在问题。

## 3. 单位经济：哪些能算，哪些不能算

| 指标 | 可用结论 | 缺失导致的限制 |
|---|---|---|
| CAC | *广泛自然使用与产品熟悉度可能降低企业获客摩擦* | 销售/推广投入及新增付费客户分母缺失，无法量化CAC |
| ARPU | 公开套餐价格是标价 | 各档位人数、地区结构、优惠和税费缺失，不能拿$20当全体平均 |
| LTV | 不计算 | 付费留存、客户生命周期及贡献毛利缺失 |
| LTV/CAC、回本周期 | 不计算 | 没有可靠CAC和LTV |
| 推理边际成本 | *随模型、缓存、上下文长度、工具调用和服务等级变化；不为零* | 批发算力成本、平均任务Token、利用率、补贴和分成缺失 |
| 规模经济/盈亏平衡 | *工程、缓存与模型分层可能改善效率，持续推理及前沿训练又增加支出* | 无分产品贡献利润及可靠现金流，不能确认已过拐点 |

2026-02-27官方披露个人订阅用户超过5000万、ChatGPT WAU超过9亿。[Scaling AI for everyone](https://openai.com/index/scaling-ai-for-everyone/) 🟢；AP同日报道同组数字，属于第二媒体确认，但仍源自公司讲话，没有独立用户测量。[AP融资报道](https://apnews.com/article/a0a915c32b85337d799fe2f9525a932a) 🟡（全文抓取失败，仅可核实搜索摘要）。

*用50 / 900 × 100得到5.56%，通过 `python3 tools/financial_rigor.py calc --expr '50 / 900 * 100'`精确验算。这个数只展示两个披露下限的比例，**不是付费转化率**：两数均为“超过”，真实比率方向未知；订阅存量也未必与当周活跃集合完全一致。不能据此计算订阅收入。*

*边际收入是否覆盖边际成本，应按成功交付任务衡量：任务收入减去模型推理、工具、云服务、渠道及人工监督成本。Token单价下降可能扩大需求，但它也表明能力商品化与定价压力。没有成本曲线，低价不是高利润证据。*

## 4. 产品矩阵、阶段与飞轮

| 产品族 | 用户与用途 | 研究阶段判断 |
|---|---|---|
| ChatGPT个人层 | 学习、写作、信息决策、多模态创作 | *已规模化；留存和渗透仍有成长空间* |
| Business/Enterprise/Edu等组织层 | 知识工作、企业数据连接、权限管理 | *扩大商业化；信息治理提高采用门槛也提高粘性* |
| Codex / ChatGPT Work | 编程、研究与跨工具专业工作 | *从辅助向执行迁移，使用强度比纯人数更关键* |
| 模型API / Agents API | 下游应用及生产工作负载 | *平台业务扩张，客户也可以多模型路由* |
| Dots、Space、Pages、插件等 | 持续代理与协作工作空间 | *新发布能力，不能把发布当留存或利润验证* |
| 商业意图层 | 广告、购物及企业Marketplace | *不同成熟度的新变现路径，公开收入拆分不足* |

2026-09-29 DevDay官方一次公布超过20项能力，包含Dots、GPT-6.1 Sol、插件扩展、Space/Pages及新Pro档位。*这反映迭代密集，也增加产品复杂度、维护成本和用户学习负担；未来数季需要验证新工作流是否增加付费留存而不只是带来发布日流量。* [DevDay 2026 Recap](https://openai.com/index/devday-2026-recap/) 🟢发布事实；商业效果为🟡推理。

*飞轮一：消费者熟悉产品 → 员工带入工作 → 企业统一采购治理 → 更多工作负载。飞轮二：模型研发 → 多产品共用能力 → 使用与收入 → 进一步研发和算力投入。飞轮三：开发者/插件补充场景 → 平台更有用 → 吸引用户与开发者。*

*反向检验：飞轮二可能变成“需求增长 → 推理亏损扩大 → 更多融资”的资本消耗循环；飞轮三若开放协议让生态多归属，OpenAI未必独占收益。企业隐私政策默认不将企业/API数据训练模型，因此不能写成“所有企业客户数据自动改善通用模型”。[Business data](https://openai.com/business-data/) 🟢政策。*

## 7. 定价权与护城河

*定价权评为3 / 5（中等）：品牌和高价值执行支持分层定价，但API降价、低价Go和多模型替代限制普遍提价。推出更高档位不等于原有价格上调，也不等于证明提价不流失。过去三年一致可复核的提价后留存数据缺失。*

| 护城河 | 评分（判断） | 支持证据与反证 | 趋势/持久性 |
|---|---|---|---|
| 网络效应 | 3 / 5 | 开发者/插件增加场景；单个问答用户并不会自然使别人得到更大效用，非社交网络型强网络效应 | *生态扩张，但多归属削弱独占* |
| 转换成本 | 3 / 5 | 个人轻任务易切换；企业权限、工作流、评测和数据连接增加迁移成本 | *个人窄，组织可能加宽* |
| 品牌心智 | 5 / 5 | 数亿级官方周使用支持品类认知；没有独立NPS，声誉冲击仍可能伤害信任 | *强，但不等同永久定价权* |
| 数据壁垒 | 3 / 5 | 使用反馈可改善产品；企业数据默认不训练、消费者可退出，竞争者亦可合成数据 | *中等，不能拿所有对话作独占训练资产* |
| 监管牌照 | 1 / 5 | 未发现独占经营牌照；合规能力是进入成本而非明确独占权 | *弱；监管也可能是成本* |
| 规模经济 | 4 / 5 | 研发摊销、缓存、模型路由和采购可能形成效率优势；持续算力承诺与竞争降价是反证 | *有潜力，净利润尚待验证* |

综合商业护城河：**中等，品牌和分发最强；企业工作流可能加宽，通用模型能力具有衰减风险。** 评分不是通过六项简单平均所得的投资评级。

## 8. 国际化与关键验证点

2026-01 Go开始覆盖所有ChatGPT可用地区（“全球可用”不代表所有国家均获服务）；此前已从印度扩展到170个额外国家。[Go发布](https://openai.com/index/introducing-chatgpt-go/) 🟢。本地定价、语言表现、数据驻留和支付能力决定海外付费效率。**海外收入比例、按国收入、汇率及渠道分成数据缺失。**

| 验证点 | 应取得的证据 | 什么结果会改变判断 |
|---|---|---|
| 规模是否变利润 | 按产品贡献毛利、推理成本/成功任务、免费层补贴 | *收入增加但贡献亏损持续扩大，商业评分应下调* |
| 使用是否变留存 | 付费cohort、月流失、企业NRR、部署续约 | *新增使用无法抵消付费退出，分发优势价值下调* |
| 智能体是否能执行 | 经人审后的任务完成率、错误损失、监督成本 | *需要大量人类补救，不能用理论人工工资当节约额* |
| 免费变现是否伤信任 | 广告负载、收入/活跃用户、回答信任及订阅降档 | *广告提高收入却降低付费留存，飞轮出现冲突* |
| 生态是否独占收益 | 开发者留存、平台收入占比、多模型份额 | *下游成功但算力/云/插件攫取主要利润，OpenAI估值需下降* |

## 9. 交叉验证与本维度结论

关键来源至少有官方原文与媒体转述，但**官方与引用同一官方数据的媒体不是两个独立测量来源**。本维度未找到可审核的全球用户独立去重测量、财务收入分部或付费留存。因此12亿周用户可以作为公司规模声明，而不能包装为独立验证后的财务指标。较旧9亿数据不能推翻新12亿，因日期和口径均不同。

最重要的三个发现：

1. *OpenAI已经有真实且广泛需求，品牌分发能帮助企业采用；需求证明强于利润证明。*
2. *收入正从购买聊天访问延伸到购买持续工作负载，长期价值取决于任务贡献利润而不是消息量。*
3. *最强的可持续壁垒可能是工作流与生态，单独模型领先和全体用户数据独占的论证不充分。*

最大盲区：**不同产品、地区与使用强度下的贡献毛利和付费cohort留存**。缺失这些资料，可以判断生意值得深入研究，但无法据本维度给出可靠内在价值或确认高估值安全边际。
